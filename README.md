# Денорс — Security Store

Собственный интернет-магазин систем безопасности: PHP 8.3+, серверный HTML,
модульный CSS, Vanilla JavaScript, MySQL/MariaDB через PDO. Без WordPress и тяжёлых
фреймворков. Замена действующего сайта допускается только после проверки переноса
данных и SEO и отдельного разрешения владельца.

## Текущий этап

Аудит Timeweb и настройка staging частично завершены, подтверждена отдельная БД.
Подготовлен PHP-каркас и точный маршрутизатор для сохранения исторических путей.
29.10.2026 владелец отложил Basic Auth технического домена и разрешил дальнейшую
разработку. Deploy снова использует публичный HTTPS + noindex smoke.
