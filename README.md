# Денорс — Security Store

Собственный интернет-магазин систем безопасности: PHP 8.3+, серверный HTML,
модульный CSS, Vanilla JavaScript, MySQL/MariaDB через PDO. Без WordPress и тяжёлых
фреймворков. Замена действующего сайта допускается только после проверки переноса
данных и SEO и отдельного разрешения владельца.
