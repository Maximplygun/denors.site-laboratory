## Устройство

При ширине ≤40rem шапка показывает нативный details/summary «Меню сайта».
На большей ширине отображается прежняя настольная навигация. Лозунг остаётся
видимым на всех ширинах. Меню раскрывается в потоке документа и не перекрывает
содержимое; прокрутка не блокируется, ловушки фокуса нет.

Ссылки «Главная / Контакты» вынесены в общий site-nav-links.php: обе версии
используют один источник. CSS скрывает неактивную версию, в том числе от Tab
и дерева доступности. Не создаются новые id, URL, категории, корзина или поиск.
Маршруты, БД, главная и footer не менялись. Компонент работает также на 404.

mobile-navigation.css подключается после site-shell.css. Vanilla JS-модуль
mobile-navigation.js подключается шапкой через type=module и выполняется после
разбора документа. Подключения версионированы `?v=day8`.
Глобальных переменных, runtime-зависимостей, таймеров и повторного init нет.
Обработчики живут вместе со статическим документом; SPA/динамического удаления
шапки сейчас нет. При будущем добавлении такого жизненного цикла потребуется
явное отключение обработчиков перед повторной инициализацией.

## Поведение

- Enter/Space на summary раскрывает или закрывает меню. Состояние доступности
  expanded/collapsed предоставляет браузер; дублирующий aria-expanded не нужен.
- Escape из открытого меню закрывает его и возвращает фокус на summary.
- Выбор ссылки закрывает меню, сохраняя обычную навигацию. Контактный якорь
  переводит фокус к site-contacts, включая страницу 404.
- Клик вне меню закрывает его; фокус не остаётся на скрытой ссылке.
- При пересечении breakpoint меню закрывается. Если фокус был в скрываемой
  навигации, он переносится в видимую. Учтено, что браузер может сбросить фокус
  на body до события matchMedia change.
- Без JS нативное раскрытие и ссылки работают. Автоматическое закрытие по
  Escape/выбору/внешнему клику не гарантируется без модуля: повторное нажатие
  summary закрывает меню. Содержимое доступно без скриптов.

успешные HTTP-проверки, CSS 200/text/css и JS 200 с JavaScript MIME.
