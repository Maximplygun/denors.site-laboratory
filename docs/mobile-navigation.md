# Мобильная навигация — редизайн Дня 8

Статус REVIEW. Широкий details-блок заменён компактной шапкой и правой
модальной панелью. Следующий этап не начат. Production не изменялся.

## Реализация

Существующий breakpoint 40rem (640 px при базовых 16 px) сохранён. На мобильном:
основная строка 68 px, логотип и SVG-гамбургер 48×48 px; уведомление уменьшено.
Описание и подпись логотипа скрыты только в шапке на мобильном по новой задаче.
Точный лозунг сохранён в desktop header и footer. Десктопные стили не менялись.

Нативный dialog выводит панель поверх страницы, делает фон inert и ограничивает
фокус. Дополнительно обработан цикл Tab/Shift+Tab. aria-controls/expanded
переключателя синхронизированы, кнопки имеют доступные подписи.
Панель min(340px, 88vw), 100dvh с 100vh fallback; overlay 40%, без blur.
Анимация transform 260 ms на открытие и 220 ms на закрытие, overlay opacity;
учтён prefers-reduced-motion. Навигация прокручивается отдельно, CTA учитывает
safe-area. Тело фиксируется с компенсацией scrollbar и восстановлением styles
и scrollY; pagehide также снимает блокировку перед уходом со страницы.

Один server-rendered nav перемещается между исходной позицией и панелью,
без клонирования DOM. Реальные ссылки и их порядок сохранены: Главная, Контакты.
Вложенных категорий в проекте нет, поэтому не добавлен неиспользуемый accordion.
При появлении реальной иерархии её раскрытие потребует отдельной реализации.
Без JS или showModal остаются обычные HTML-ссылки в шапке, кнопка скрыта.
Старые details-разметка, CSS и обработчики удалены.

Закрытие: X, overlay, Escape, ссылка, переход на desktop. После обычного
закрытия фокус возвращается на гамбургер; после ссылки сохраняется её нативный
переход и якорный фокус. На desktop nav возвращается на прежнее место.
При закрытии по ссылке нет искусственной задержки, чтобы не терять default action.
Меню не вызывает history.pushState и не перехватывает браузерную кнопку Назад.
Модуль исполняется один раз в статическом документе, без сторонних зависимостей.

## Проверки и ограничения

Проверены в браузере ширины 320, 360, 375, 390, 400, 430, 768, 1024 px:
горизонтального переполнения нет, nav один, мобильная строка 68 px.
Проверены открытие, X/Escape/overlay, Tab/Shift+Tab, контактный CTA,
повторные открытия, перенос nav на desktop, блокировка/разблокировка body.
Координатный клик по частично видимому гамбургеру подтвердил сохранение scrollY
40 px; локаторы обычно прокручивают кнопку в видимую область до клика.
Консоль без ошибок/warnings. Ссылки, PHP и HTTP-регрессия проверены отдельно.

Lighthouse, реальные сенсорные устройства, screen reader и замер CLS не выполнены.
Полный аудит производительности не заявляется. Независимая прокрутка панели
предусмотрена CSS; текущие две ссылки не создают длинного списка.
Reduced-motion и safe-area реализованы, но реальное устройство не проверялось.

## Как проверить в Chrome DevTools

1. Открыть staging после доставки, включить Device Toolbar и обновить кэш.
2. Проверить все указанные ширины; 640/641 px — граница мобильного/desktop вида.
3. Открыть гамбургер: справа панель и overlay, кнопка X получает фокус.
4. Проверить Tab/Shift+Tab, Escape, X и клик слева от панели. После закрытия
   фокус на гамбургере, body без inline-блокировки; прокрутка восстановлена.
5. Выбрать Контакты или CTA: панель закрывается, контактный блок получает фокус.
6. Открыть панель и перейти на 768/1024 px: видна прежняя настольная навигация,
   блокировка body снята. Проверить также неизвестный путь с HTTP 404.
7. В Rendering эмулировать prefers-reduced-motion: анимация отключается.
8. В Network проверить 200 CSS/JS версии offcanvas1 и корректный JS MIME;
   в Console не должно быть ошибок. Заблокировать модуль и перезагрузить:
   вместо гамбургера доступны обычные ссылки.
9. Проверить Performance/Layout Shifts при открытии/закрытии и на реальном
   сенсорном устройстве, включая safe-area и browser Back.

Для доставки только на staging из корня проекта: `denors check`, затем `denors`
после коммита и с чистой рабочей папкой; команда отправляет ветку в GitHub.
После доставки: `bash tests/http-staging.sh`. В этой задаче deploy не выполнялся.
