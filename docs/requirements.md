# Аудит требований — День 1

Дата: 26.10.2026.

## Подтверждено локально

Рабочая папка до начала работ содержала только `.git`. Репозиторий без коммитов,
текущая ветка `master`, remote отсутствует. Исходников приложения и экспорта нет.

## Обязательные ограничения

- PHP 8.3+, PDO, MySQL/MariaDB; HTML5, CSS3, Vanilla JS; серверный рендеринг.
- Собственная админка: серверная авторизация, роли, CSRF, защита от XSS,
  подготовленные запросы, безопасная загрузка файлов и журнал изменений.
- Публичный корень только `public/` либо доказанно эквивалентная изоляция.
- Конфигурация, приватный код, логи, резервные копии — вне публичного корня.
- Существующий WordPress и его настройки не изменять без разрешения владельца.
- Сохранить фактические пути, слеши, canonical, SEO и медиа. Не проектировать
  товарные и категорийные маршруты до получения фактической карты URL.
- Формат импорта и итоговая схема данных определяются по реальному экспорту.
  Импорт: предпросмотр, dry-run, повторяемость без дублей, журнал и сверка.
- Реальные категории, отзывы, цены, контакты и юридические сведения не выдумывать.
- Онлайн-оплата — после выбора провайдера; IndexNow — после согласования.
- Дизайн: светлый каталог, заданная палитра, локальный Onest/Inter, отдельные
  компоненты header/footer/карточек/фильтров и доступная мобильная навигация.
- Цели после запуска на реальных данных p75: LCP ≤ 2.5 с, INP ≤ 200 мс,
  CLS ≤ 0.1. Лабораторные показатели не заменяют полевые.

## Предварительное архитектурное направление

После утверждения Дня 1 и завершения Дня 2: компактная MVC-подобная архитектура,
автозагрузка, отдельные контроллеры, сервисы, репозитории PDO и PHP-шаблоны.
Точный router и схема БД не утверждены до анализа URL/экспорта.
Миграции версионируются. Runtime и загрузки отделяются от кода релиза.
Основной вариант доставки — отдельные релизы с атомарным переключением ссылки,
только если это поддерживает хостинг. Иначе потребуется отдельно проверенная
процедура с резервированием и временной блокировкой записи.

## Риски и меры

| Риск | Решение до реализации |
| --- | --- |
| Возможности тарифа неизвестны | Проверить матрицу hosting.md; не устанавливать инфраструктуру заранее |
| CLI и web используют разные PHP | Проверить отдельно версию, расширения и ini обоих SAPI |
| Приватные файлы доступны из web | Подтвердить document root и HTTP-запреты до загрузки приложения |
| Потеря SEO при замене движка | Собрать эталон URL, статусов, canonical и метаданных до маршрутизации |
| Несогласованный откат БД | Совместимые миграции либо отдельная процедура восстановления данных |
| Тестовые заказы уходят клиентам | Отдельная БД, тестовая почта, отключённые реальные платежи |
| Не хватает ресурсов для импорта | Пакеты и CLI/Cron после измерения доступных ограничений |

Полезное дополнение: получить до проектирования маршрутов read-only выгрузку
sitemap, настроек permalink и Yoast, а также перечень исторических редиректов.
Это позволит проверить сохранность URL по эталону, а не по предположениям.
