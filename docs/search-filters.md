## Реализация

- SearchQuery: строгий разбор GET-параметров q/min/max/sort/page. Только строки
  UTF-8, запрос до 120 символов, нормализация пробелов. Цена от 0 до 999999999,99,
  точка или запятая, максимум две цифры копеек, без float. Обратный диапазон,
  массивы параметров, неизвестная сортировка и некорректная страница отклоняются.
- SearchItem: ProductDetails и неизменённый originalPath. Общая проверка пути
  вынесена в OriginalPath; CategoryLink использует её без изменения допустимых URL.
- ProductSearch: эталонная реализация в памяти для изолированных fixtures.
  Поиск без учёта регистра кириллицы в названии/SKU/описании, все слова должны
  присутствовать. Это не полнотекстовый индекс и не готовый SQL-репозиторий.
- Фильтр цены включительный. При активных границах неизвестная цена исключается;
  ноль — отдельное известное значение. Сортировка исходная, цена asc/desc, название.
  В ценовой сортировке неизвестные цены всегда в конце, равенства стабилизированы
  оригинальным путём. Сортировка по названию использует сравнение UTF-8 после
  lower-case, не языковую коллацию или «естественную» сортировку чисел.
- Пагинация по 12 записей; страница за диапазоном показывается как последняя,
  без автоматических редиректов. Ссылки сохраняют запрос, границы и сортировку;
  новая отправка формы начинает с первой страницы.
- search.php и search.css: серверная GET-форма, текстовые карточки результатов,
  пустая выдача, сообщение ошибки и сброс. Доступны без JS; обновление страницы
  сохраняет URL, браузерный Back работает обычным образом. Вывод экранируется.

Категории/бренды/атрибуты не выдумываются: фасеты определяются по реальным данным.
Не добавлены автодополнение, поиск с опечатками, корзина, БД или новые публичные
маршруты. Application/Router и SEO-конфигурация не менялись. Preview noindex.
Production canonical/индексация комбинаций фильтров определяются отдельно до
публичного подключения. Текущий reference engine нельзя выдавать за завершённый
поиск по полной БД: масштабирование и индексы проверяются после схемы/экспорта.

## Локальная проверка

```bash
php tests/search.php
php -S 127.0.0.1:8103 -t public tests/search-preview-router.php
```

Открыть http://127.0.0.1:8103/__search-preview/.
Данные явно тестовые, 30 записей; пути берутся из аудиторского CSV только как
fixtures. Ссылки неимпортированных товаров ведут к 404. Это не страница магазина,
preview-router находится за пределами public и разрешён только для CLI-server.
Не назначать его публичной точкой входа; после проверки остановить сервер.

Сценарии: запрос ДАТЧИК, цена 100,50–1000 и убывание дают четыре тестовых товара;
поиск TEST-2 проверяет SKU. Сброс показывает исходную выдачу, «Следующая» — страницу 2.
От 2000 до 1000 показывает ошибку, сохраняя поля; бессмысленный запрос — пустую
выдачу. Попробовать reload/Back, Enter в форме и Tab/Shift+Tab.
