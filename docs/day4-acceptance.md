# День 4 — приёмка на Timeweb

Проверяется только staging denors.site-laboratory.ru. Production denors.ru
не менять. Магазин пока содержит служебную главную; исторические страницы
до импорта должны возвращать 404, а не пустые страницы с 200.

## Локально, Git Bash

Из корня проекта после коммита:

```bash
php tests/application.php
php tests/routing.php
bash -n tests/http-staging.sh
denors check
```

`denors check` подключается к Timeweb и выполняет Linux-тест переключения/отката
в изолированной папке, не меняя публичный корень. Требуется PASS.

Для локальной HTTP-проверки запустить в отдельном терминале
`php -S 127.0.0.1:8087 -t public public/index.php`, затем
`bash tests/http-staging.sh http://127.0.0.1:8087`. Явный router нужен для
передачи отсутствующих .php-путей в приложение. После проверки остановить сервер.
Это проверяет PHP-ответы, но не Apache/Nginx.

## Публикация и проверка staging владельцем

```bash
git status --short
git branch --show-current
denors
bash tests/http-staging.sh
git rev-parse HEAD
curl -q --fail --show-error https://denors.site-laboratory.ru/denors-release.txt
```

Перед denors рабочая папка должна быть чистой; ветка develop или feature/*.
Команда denors отправляет текущую ветку в GitHub и публикует именно её коммит
на staging. Ожидается `HTTPS 200 + noindex verified.`; идентификатор release
должен совпадать с git rev-parse HEAD. При отказе не обходить проверки.

HTTP-тест не следует редиректам и не отключает проверку TLS. Он проверяет
200 главной, HEAD, 405 с Allow, 404 неизвестных/неимпортированных/приватных
путей и noindex; /.env допускает серверный 403 либо 404.
Реальный 404 с HTML-заголовком подтверждает прохождение неизвестного пути
через приложение и позволяет выявить отсутствие Apache rewrite.
HEAD проверяется по статусу и заголовкам; отсутствие тела дополнительно
проверяется серверной реализацией Response и локальными HTTP-проверками.

В браузере открыть главную и /denors-day4-missing/: проверить русский текст,
отсутствие PHP-ошибок и ссылку возврата на главную. Статусы сверять в Network.
Не ожидать дизайн магазина: он относится к последующим дням.
