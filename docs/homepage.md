## Архитектура и SEO

HomeController рендерит pages/home.php. Весь контент и ссылки доступны без JS.
home.css подключается только на главной, классы ограничены home-*.
Локальная декоративная security-system.svg — схема, не фото товара или объекта.
У img пустой alt, заданные width/height, fetchpriority=high; она не добавляет
внешних запросов. Размеры новых файлов: CSS 4046 байт, SVG 2213 байт.
Нет слайдеров, внешних виджетов, форм, бизнес-операций или новых зависимостей.

Заменённый шаблон pages/staging.php и design-preview.css удалены, чтобы не
оставлять неиспользуемые образцы в runtime. Общие токены и компоненты сохранены.
Существующая проверка h1 в tests/application.php принимает атрибуты, включая id
для aria-labelledby; её прежний поиск только буквального `<h1>` был слишком строгим.

Единственный маршрут `/`, HTTP-контракт, старые пути и robots не изменены.
Один h1, последовательные h2/h3, title/description, OpenGraph и Twitter summary.
Noindex staging сохранён. Production canonical, og:url, sitemap и структурированные
данные с production-идентификаторами не генерируются до подтверждения домена,
контента и канонической политики. Перед production нужно согласовать метаданные
главной с эталоном старого сайта — это не готовый production SEO-release.
